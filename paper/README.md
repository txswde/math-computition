## 目录结构

- `main.tex`：论文主文件与参赛信息
- `gmcmthesis.cls`：2026 华为杯论文类
- `gmcm.bst`：参考文献样式
- `reference.bib`：论文参考文献库
- `sections/`：正文各章节
- `figures/`：论文图片及封面固定素材目录
- `makefiles.sh` / `makefiles.bat`：一键编译脚本

## 编译

推荐安装 TeX Live，并使用 XeLaTeX：

    cd paper
    latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex

Windows 也可运行：

    makefiles.bat

macOS / Linux 可运行：

    bash makefiles.sh

## 关于封面固定 PDF 素材

参考模板使用 `figures/logo.pdf` 和 `figures/title.pdf` 生成官方风格封面。

当前仓库中的 `gmcmthesis.cls` 已加入兼容回退：若这两个 PDF 尚未放入 `paper/figures/`，则使用文字赛事标题，不会因此阻塞正文编译。正式提交前应以组委会最新官方格式文件为准，并补齐官方固定素材。
