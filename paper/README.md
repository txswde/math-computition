## 写作原则

1. 摘要结构参考上一届优秀论文的组织方式，但表述、模型与结论全部围绕本届 C 题重新组织，不复制上一届正文；
2. 正文只保留数学模型、关键实验设计、主要结果和解释；
3. 工程日志、哈希、单元测试等复现信息放附录或仓库；
4. 所有第二、三问文字必须与最终代码和数值结果一致；
5. 不根据结果反向挑选时间窗、电极或统计口径；
6. 不把三通道头皮 EEG 解释成唯一的 LGN、海马或皮层三维源定位。
