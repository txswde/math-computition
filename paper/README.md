# paper

二十三届中国研究生数学建模竞赛 C 题论文 LaTeX 框架。

## 编译

推荐使用 **XeLaTeX**。在项目根目录进入 paper 后执行：

    xelatex main.tex
    xelatex main.tex

主文件：main.tex

章节文件位于：sections/

## 写作原则

1. 正文只保留数学模型、关键实验设计、主要结果和解释；
2. 工程日志、哈希、单元测试等复现信息放附录或仓库；
3. 所有第二、三问文字必须与最终代码和数值结果一致；
4. 不根据结果反向挑选时间窗、电极或统计口径。
