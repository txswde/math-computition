\section{模型评价与敏感性分析}

\subsection{模型优点}

\begin{enumerate}[label=(\arabic*)]
    \item \textbf{以保真为首要约束，而非单纯追求平滑。} 第一问通过已知波形注入显式检查视觉响应幅值和峰时是否被算法破坏，使降噪方法具有可验收标准。
    \item \textbf{三问形成统一的数据—机制—认知链路。} 第一问输出的保真EEG和ERP直接作为第二问的观测约束，第二问得到的视觉响应特征继续作为第三问输入，避免各问使用互不相干的黑箱模型。
    \item \textbf{尽量避免信息泄漏和事后挑选。} 学习型预处理和超参数选择在训练折内进行，并预先固定晚期窗口和主统计协议；历史测试结果与开发阶段结果明确区分。
    \item \textbf{强调可辨识性边界。} 对三通道EEG不进行唯一脑源定位；对P300、海马状态等生理概念只有在数据和模型共同支持时才作有限解释。
    \item \textbf{具有较强的可复现性。} 第一问已保存逐试次处理结果、参数化曲线、统计检验、敏感性分析及复现日志，后续问题继续沿用统一的数据接口和验证协议。
\end{enumerate}

\subsection{模型局限}

\begin{enumerate}[label=(\arabic*)]
    \item F3、Fz、F4仅有三个头皮通道，空间信息有限，无法唯一恢复LGN、海马及完整皮层的真实三维活动；
    \item 当前数据缺少可靠物理单位标定，幅值分析只能在记录单位下进行；
    \item 第一问左右刺激差分的分半稳定性较弱，说明形状差异可能需要多通道联合动力学才能稳定描述；
    \item 部分晚期响应对滤波边界和慢漂移处理较敏感，因此不应仅凭单一预处理分支宣布稳定P300；
    \item 问题三中的记忆状态属于功能性潜变量，必须通过模型比较证明其必要性，不能等价为直接测得的海马电活动。
\end{enumerate}

\subsection{第一问敏感性分析}

现有结果显示，实验项目II/Fz在$250$--$500\,\mathrm{ms}$窗口下的共同效应会随预处理方案变化：主$\Pzero$分支呈负向晚期变化，而仅低通分支可出现方向翻转；扩大滤波边界后效应方向仍为负，但显著性减弱。这表明晚期ERP对低频漂移和边界上下文存在敏感性。因此，本文不从多个预处理分支中挑选“最显著”的一个作为结论，而把不同分支作为稳健性边界报告。

此外，对不同统计块长度的检验显示主要效应数值相对接近，但条件性$p$值随有效块数和相关结构变化。故统计结果用于描述本数据内部的稳定性，不直接外推为总体人群效应。

\subsection{问题二、三的待补敏感性}

第二、三问完成后，将围绕以下因素补充敏感性与消融分析：视觉输入延迟、E/I耦合强度、观测矩阵正则强度、记忆耦合项、潜在状态维数以及时间窗终点等。所有敏感性分支仅用于判断结论是否稳健，不通过选择最优分支来反向修改主模型。
