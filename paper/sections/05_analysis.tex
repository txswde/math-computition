\section{问题分析}

三问并非彼此独立，而是沿着“\textbf{从观测到机制、再从机制到认知}”逐层深入。问题一首先解决原始EEG是否可信、哪些视觉响应可以稳定提取；问题二在此基础上回答这些观测曲线可能由怎样的视觉输入和神经群体动力学生成；问题三再进一步引入记忆与认知状态，使模型能够描述从“看见刺激”到“识别刺激”的过程。基于这一层次关系，本文统一采用“观测数据约束模型、模型输出回到观测验证”的闭环思路，而不是将三个问题割裂处理。

\subsection{问题一分析}

问题一的核心矛盾并非单纯“最大程度去噪”，而是“在抑制伪影的同时尽可能保留未知的视觉任务特征”。题目已明确指出，现成滤波通道虽能去除部分干扰，却可能同时破坏视物相关特征。因此，如果只比较滤波后的平滑程度或信噪比，很容易得到一个视觉响应已经被削弱的“干净信号”。

据此，本文将问题一拆分为四个递进环节：

\begin{enumerate}[label=(\arabic*)]
    \item \textbf{构建低偏差参考。} 从原始F3、Fz、F4出发，通过零相位带通与局部基线校正建立保真参考$\Pzero$；
    \item \textbf{提高跨试次稳健性。} 不简单丢弃异常试次，而根据峰峰值、RMS、一阶差分MAD和异常幅值比例建立质量权重$\Wzero$；
    \item \textbf{受约束地尝试进一步降噪。} 以共同响应和左右差分构造候选响应子空间，仅对其正交补空间实施正则平滑，并在训练折内选择模型；
    \item \textbf{先验验收再做生理解释。} 通过人工已知信号注入、分半稳定性、留出预测和敏感性分析检验方法是否真正做到“去噪不毁信号”，最后才提取ERP并进行参数化拟合。
\end{enumerate}

这一思路使问题一的目标从“找到最复杂的滤波算法”转化为“找到在当前数据上经过保真验收的处理算法”。

\subsection{问题二分析}

问题二要求从“观测差异”进一步过渡到“生成机制”。题目给出的生理背景提示，不同形状的视觉刺激可通过特定空间特征排列引起不同神经群体响应，而头皮EEG是大量神经元活动在空间和体积传导作用下的综合观测。因此，仅训练一个左右分类器虽然可能获得判别结果，却无法回答“差异如何形成”。

本文将问题二划分为三个层级：

\begin{enumerate}[label=(\arabic*)]
    \item \textbf{刺激表征层：} 将左/右三角形转化为具有方向和相对空间位置意义的低维视觉输入；
    \item \textbf{神经动力学层：} 采用共享参数的兴奋/抑制神经群体动力学描述LGN输入作用于皮层后的时序演化；
    \item \textbf{观测层：} 通过低维观测矩阵将潜在皮层状态映射到F3、Fz、F4三通道，并用问题一得到的ERP曲线进行参数估计和留出验证。
\end{enumerate}

最终，左右刺激的可区分性不应只由分类准确率体现，还需要表现为模型中可解释的空间输入差异、状态轨迹差异或通道联合响应差异。

\subsection{问题三分析}

问题三把研究对象从“直接视觉响应”推进到“视觉认知”。题目将认知过程简化为“看见视物—从记忆区域寻找并对照信息—识别视物”，并提示认知信号可能同时受到LGN与海马体等来源影响。因此，问题三适合在问题二的视觉生成机制上增加一个\textbf{记忆/认知状态子系统}，而不是重新建立与前两问无关的黑箱分类模型。

同时，题目提醒实际应答可能错误或缺失，这意味着行为事件只能用来辅助界定认知分析区间，而不能直接作为认知状态真值。由此，问题三的验证重点应放在：模型能否解释两个实验项目因“已知目标位置/未知目标位置”造成的状态轨迹差异，能否在不依赖行为正确性的情况下重建相应EEG，以及记忆状态模块是否对模型拟合具有不可替代的贡献。
